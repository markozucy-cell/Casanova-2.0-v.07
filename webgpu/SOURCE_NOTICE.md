# WebGPU V2 browser source

`casanova_engine_v2.js` is the actual JavaScript engine source extracted from the CASANOVA V2 browser build.

`CASANOVA_V2_SOURCE_NO_EMBEDDED_GLBS.html` preserves the game UI, source and inline map imagery but removes its 19 embedded original GLBs to stay under GitHub's normal file limit. Open the **67 MODELS** panel in the browser and select original GLB files from your device to populate the game. The 116 MB self-contained HTML build is **not uploaded yet**.

This version is an unverified development prototype; full 3D realism and mobile performance are not guaranteed.
