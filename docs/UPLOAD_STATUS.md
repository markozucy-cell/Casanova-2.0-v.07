# Upload status

This repository currently contains game documentation and a Git LFS configuration. The original **67 GLB models**, the Godot project source files, and the 116 MB browser playable HTML are **not yet uploaded**. This must not be mistaken for the full game backup.

The GitHub connector cannot transfer local container files directly, and ordinary GitHub files over 100 MB cannot be committed without Git LFS.

Asset total: approximately 1.92 GB. Do not publish third-party GLBs without checking their licenses.
